Black Friday Deal Finder — 34 real Black Friday and Cyber Monday 2026 deals from Amazon, Best Buy, Nintendo, Costco, Target, Kohl's, Yodobashi, Bic Camera and more, every price checked on 27 November 2026. Search, filter by category and store, sort by discount or saving, switch between $ and ¥, and open any deal for its detail page. Static site, no build step, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
